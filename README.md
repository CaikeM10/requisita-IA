## Descrição da ideia

RequisitaIA é um assistente de inteligência artificial para levantamento inicial de requisitos.  
Desenvolvedores recebem pedidos informais, muitas vezes incompletos.  
Isso dificulta definir o escopo e entender o que o cliente espera.  
A aplicação atende estudantes e desenvolvedores de pequenos projetos.  
O usuário informa um relato textual sobre o sistema que deseja construir.  
A IA sugere requisitos, critérios de aceite e perguntas de esclarecimento.  
O usuário revisa, edita e exporta a proposta em Markdown.  
Espera-se reduzir retrabalho e obter um escopo inicial mais claro.

## Stack tecnológica inicial

- **IDE:** Visual Studio Code.
- **Linguagem:** TypeScript.
- **Framework:** Next.js.
- **Biblioteca de interface:** React.
- **Estilização:** CSS.
- **Inteligência artificial:** API de modelo de linguagem, com provedor a definir pela dupla.
- **Versionamento:** Git e GitHub.

## Justificativa técnica

TypeScript ajuda a organizar os dados e reduzir erros de tipagem.
Next.js permite reunir a interface e o processamento no servidor em um mesmo projeto.
A API de inteligência artificial será utilizada para interpretar os relatos e sugerir requisitos, critérios de aceite e perguntas de esclarecimento.
As sugestões serão revisadas pelo usuário antes da exportação.
Git e GitHub permitem registrar a evolução do projeto e colaborar em dupla.

Essa combinação mantém o escopo inicial viável e apoia o desenvolvimento orientado por especificações (Spec-Driven Development — SDD) ao longo da disciplina.

## Funcionalidades previstas

1. Receber uma descrição textual do sistema desejado.
2. Sugerir requisitos com apoio de IA.
3. Propor critérios de aceite.
4. Gerar perguntas para esclarecer informações ausentes.
5. Permitir revisar e editar as sugestões.
6. Exportar o documento revisado em Markdown.
